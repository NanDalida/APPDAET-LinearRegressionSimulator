# APPDAET – Least Squares Regression Simulator

### Group 5 | Application Development Final Project

---

## Project Overview

Hello! Welcome to our group's final project for **Application Development (APPDAET)**.

The **Least Squares Regression Simulator** is a Python-based application designed to help users analyze numerical datasets and understand how regression models work through mathematical calculations and visualizations.

The simulator aims to make regression analysis easier by allowing users to upload CSV files, select numerical data, calculate regression equations, measure prediction errors, and visualize the relationship between variables.

---

## Key Features

- **CSV File Upload** – Import datasets from CSV files for analysis.
- **Data Validation** – Check numerical values and exclude invalid data.
- **Regression Calculations** – Calculate regression coefficients using least-squares methods.
- **Pearson's Correlation Coefficient** – Measure the strength and direction of linear relationships.
- **Residuals and Mean Squared Error (MSE)** – Evaluate the difference between actual and predicted values.
- **Y-Value Prediction** – Predict values using the calculated regression equation.
- **Data Visualization** – Display scatterplots and fitted regression lines or curves.

---

## Regression Models

The project covers five regression models:

1. **Simple Linear Regression**
2. **Quadratic Regression**
3. **Exponential Regression**
4. **Logarithmic Regression**
5. **Hyperbolic Regression**

Each regression model uses its corresponding mathematical formula to analyze the relationship between X and Y values.

---

## Technologies Used

- **Python** – Main programming language
- **CSV Module** – Reading and processing CSV datasets
- **Math Module** – Mathematical calculations
- **Matplotlib** – Data visualization
- **Tkinter** – Graphical user interface (planned)

---

## Project Objectives

Our project aims to provide a simple and accessible tool for learning regression analysis, applying least-squares calculations, comparing regression models, and understanding how mathematical predictions are made.

The simulator focuses on implementing the calculations through basic Python programming concepts, including functions, loops, conditions, parameters, and returned values.
